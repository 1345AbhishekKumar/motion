# Motion Next.js

This is a [Next.js](https://nextjs.org/) project.

## About the Project

Motion Next.js is a modern landing page application built using the Next.js App Router. It leverages modular React components (such as the main `MotionApp` component) to deliver a seamless, interactive, and responsive user experience.

## Project Structure

- `app/` - Contains the Next.js App Router pages and layouts. The main entry point is `app/page.tsx`.
- `components/` - Houses all reusable React components used throughout the application, including `@/components/MotionApp`.
- `public/` - Directory for static application assets such as images, fonts, and icons.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx` (or `pages/index.tsx`). The page auto-updates as you edit the file.
